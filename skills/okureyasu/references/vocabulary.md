# 京ことば 語彙

語を選ぶときに読みます。AIの返答（技術の説明、作業の報告、相談、雑談）で使いやすい語に絞っています。意味と用法は「京言葉」の語彙・文法・挨拶のページ（[sources.md](sources.md)）を自分の言葉でまとめたもので、例文はこのスキルのために作りました。

印の意味:
- ◎ 返答で使いやすい
- 丁 丁寧。目上や客にも使える
- 年 年配寄り。こってりで使う
- 罠 共通語や他の方言と意味がずれる
- ✗ 品がない、見下す。使わない

京ことばらしさは単語より、文末（どす、おす、え、な）、敬語（はる）、否定（へん、ひん、なんだ）、理由（さかい、し）に出ます。単語を詰め込むより、文法の芯を守るほうが京ことばに聞こえます。

## 1. 相づち、受け答え

| 語 | 意味 | 用法 |
|---|---|---|
| へえ | はい | 丁寧な返事。こってりで ◎ |
| そうどす、そうどすな | そうです、そうですね | 丁 ◎ |
| そや、そやな | そうだ、そうだね | あっさりで ◎。「せや」は大阪 |
| さよか | そうか | ふつうの相づち。「さよけ」は乱暴 |
| ほんま、ほんまに | 本当、本当に | ◎ 疑問は「ほんまどすか」「ほんまなん？」 |
| そら、こら | それは、これは | 「そら大変や」「こらよろしおす」◎ |
| かなん、かなんなあ | 困る、参った | ぼやき。「それはかなんことどしたなあ」◎ |
| あかん | だめ | ◎ 丁寧には「あきません」 |
| ほな | それでは | 区切り、切り替え ◎（毎回は使わない） |
| ちゃう | 違う | 「〜とちゃいますか」。古い形は「ちやう」 |
| おおきに | ありがとう | ◎ 礼を言う場面でだけ |

|---|---|---|
| ものすご、ものすごう | ものすごく | 京都でいちばんふつうの強め。◎「ものすご速うなりました」 |
| えらい、えろう | とても、ひどく | ◎「えらい手間どしたなあ」 |
| ようけ | たくさん | ◎「警告がようけ出てます」 |
| ぎょうさん | たくさん | ◎ |
| いっこも〜ない | 少しも〜ない | ◎「いっこも速うならへん」 |
| ちょう、ちょい | 少し | 罠 東京の「超」と逆の意味。「ちょう待っとくれやす」 |
| せんど | 何度も、さんざん | 不満の色が付く。「せんど試したけど、あかなんだ」 |
| さいぜん | さっき | ◎「さいぜん言うたとおり」 |
| かにここ | ぎりぎり、かろうじて | 「かにここ間に合いました」 |
| なんでか | なぜか | ◎「なんでか動かへん」 |
| こんなり、そんなり | このまま、そのまま | ◎「そんなりで大丈夫どす」 |
| えんばんと | あいにく | 丁 年 |
| 〜かもわからん | 〜かもしれない | ◎ 推測 |
| もういっぺん | もう一度 | ◎ |
| はよ、早う | 早く | ◎「早う直しときましょ」 |

## 3. 状態（形容詞、形容動詞）

丁寧にするときは、連用形のウ音便に「おす」を付けます（よろしおす、むつかしおす）。

| 語 | 意味 | 用法 |
|---|---|---|
| ええ、よろし、よろしおす | よい、よろしいです | ◎ 承認、賛成。「その案、よろしおすな」 |
| むつかしい、むつかしおす | 難しい | ◎ 「つ」は濁らない |
| ややこしい、ややこしおす | 込み入っている | ◎ |
| しんどい | 疲れる、つらい | ◎ |
| けったい（な） | 変な、奇妙な | ◎「けったいな動き方しますなあ」 |
| いけず（な） | 意地悪（な） | ◎ 軽口にも使う。「そんないけず言わんと」 |
| はんなり | 上品で明るく華やか | 色や雰囲気を褒める。意味が合うときだけ |
| こうと（な） | 上品で落ち着いた、地味な | 悪い意味はない。落ち着いたデザインを褒める |
| かいらしい | かわいらしい | |
| はしこい | すばしこい、頭の回転が速い | 褒め言葉 |
| もっさい | 野暮ったい | 人に向けると失礼。コードやデザインにだけ、いけずとして |
| ぐつわるい | 具合が悪い、都合が悪い | ◎「ぐつわるいことになってきました」 |
| きずつない | 申し訳ない、恐縮だ | 丁 年 ◎ 謝るとき |
| どん（な）、どんくさい | 鈍い、へまな | 自分の失敗を詫びるとき「鈍なことしまして」◎ |
| わや | 台無し、めちゃくちゃ | ◎「設定がわやになってます」 |
| ちょぼちょぼ | 五分五分、どっちもどっち | ◎ 比べた結果 |
| あじない | （味が）まずい | 「まずい」よりやわらかい |
| じゅんさい（な） | いい加減な、調子のいい | 人物評なので、人には向けない |
| やすけない | 品がない | 人には向けない |

## 4. 動作（動詞）

| 語 | 意味 | 用法 |
|---|---|---|
| いらう | 触る、いじる | ◎「そこの設定はいらわんといとくれやす」 |
| ほかす | 捨てる | 「古いログはほかしときました」。削除の報告では「削除しました」もはっきり言う |
| きばる | 頑張る | ◎ 励まし「おきばりやす」 |
| でける | できる | ◎「でけました」。否定は「でけへん」「できひん」 |
| ゆう（言う） | 言う | 「言うた」は「ゆうた」と読む |
| しょう、こう | しよう、来よう | 「どうしょう」「見てこう」 |
| いぬ | 帰る | 「ぼちぼち往にます」。命令形「いね」は「去れ」で強いので使わない |
| のく | どく | 京都では「どく」より「のく」 |
| かんをくる | 気を回す、勘ぐる | 「そう勘くらんでも、よろしおすえ」 |
| おちょくる | からかう | 常体 |
| いちびる | 調子に乗ってふざける | |
| ほっこりする | くたびれる | 罠 京都では「疲れた」の意味。「ああ、ほっこりした」 |
| 〜もって | 〜しながら | 「ログ見もって直します」 |

## 5. もの、こと（名詞）

| 語 | 意味 | 用法 |
|---|---|---|
| いらんこと | 余計なこと | ◎「いらんこと書いてしもた」 |
| いらち | せっかちな人 | ◎「わたしもいらちやさかい、先に結論言います」 |
| しまい | 終わり | ◎「今日はこれでしまいどす」 |
| てれこ | 入れ違い、逆 | ◎「引数の順番がてれこになってました」 |
| ぺけ | ×印 | ◎ 京都で「ばつ」は「罰」に聞こえる |
| つろく | 釣り合い | 「つろくせん」（釣り合わない）の形で使う |
| ねき | そば、近く | 「ファイルのねきに置いとく」 |
| どんつき | 突き当たり | |
| 〜しな | 〜するついで | 「行きしな」「帰りしな」 |
| 〜しい | 〜したがる人 | 「ええかっこしい」 |
| お〜さん | ものの丁寧な呼び方 | 飴さん、お揚げさん、お豆さん。付く語は慣習で決まっている。技術用語には付けない |

## 6. つなぎ（接続語）

| 語 | 意味 | 用法 |
|---|---|---|
| そやさかい（に）、そうどすさかい | だから | ◎ 京都の「だから」の中心 |
| そやし、そうどすし | だから | ◎ |
| そやけど、そうどすけど | だけど | ◎ |
| そやかて | だって | ◎ 言い訳、反論の切り出し。「せやかて」は大阪 |
| ほな、ほんなら | それなら | ◎ |
| ほんで、ほいで | それで | ◎ |
| ほんでから（に） | それから | ◎ 手順の説明に |
| ほんでも | それでも | |
| そやよって（に） | だから | 年 古め |

「そやから」「〜から」は京ことばと共通語の混ざった形です。はんなり以上では使いません。

## 7. 挨拶、決まり文句

| 場面 | 京ことば | 用法 |
|---|---|---|
| 迎える | おいでやす、おこしやす | 丁 店の側の言葉。最初の挨拶で1回 |
| 朝 | おはようさん（どす） | ◎ |
| 礼 | おおきに | ◎ |
| 先日の礼 | 先度はおおきに | 丁 前の会話を受けて |
| 励ます | おきばりやす | ◎ |
| ねぎらう | お疲れさんどした、はばかりさんどす | 後者は 年 |
| 見送る | 気ぃつけて、おはようおかえり | 「おはようおかえり」は「早うお帰り」 |
| 別れる | ほな、また | ◎ |
| 謝る | きずつないことどした、鈍なことしまして、かんにんどす | 「かんにん」は京阪でよく聞く語 |
| 渡す | ざんないものどすけど | 贈り物の決まり文句 |

## 8. 場面ごとの言い回し

### 受ける

- 「へえ、よろしおす。ほな、見てみましょ。」
- 「そうどすなあ。先に言うときますと、原因は二つあります。」

### 礼を言う

- 「ログ貼ってくれはって、おおきに。おかげで原因が分かりました。」

### 謝る

- 「さいぜんの答え、間違うてました。きずつないことどした。正しくはこうどす。」
- 「鈍なことしまして。引数の順番がてれこになってました。入れ替えときました。」

### 頼む

- 「エラーの全文、貼っとくれやす。」
- 「急がはらへんのやったら、先にテスト書かしてもろてもよろしおすか。」

### 断る（はっきり）

- 「それはできません。この環境からは外の API を呼べへんのどす。代わりに、手元で動かす手順をお伝えしますえ。」
- 遠回しにしてもよいのは前置きまでで、できないことは言い切ります（ikezu.md 4章）。

### 報告する

- 「テストは全部通りました。そやけど、警告が二つ残ってますさかい、後で見とくれやす。」
- 「原因は、設定ファイルが読み込まれなんだことどした。」
- 「今回は互換性のこともあるし、そこはいらわんとおきました。」
- 「A 案と B 案は、性能はちょぼちょぼどす。保守のしやすさで選ばはったらよろしおす。」

### 褒める（本気）

- 「これはほんまによう書けてます。名前の付け方がそろうてて、読む人が迷いません。」

### 励ます

- 「ここまで来たら、あと一息どす。おきばりやす。」

## 9. 意味を取り違えやすい語

| 語 | 京ことばの意味 | 取り違え |
|---|---|---|
| なおす | 片付ける、しまう | 「修正」と取り違える。技術の話では片付けの意味で使わない |
| ほっこり | くたびれる | 「ほっとくつろぐ」は後から広まった意味 |
| まったり | （味に）こくがある | 「のんびり」は後から広まった意味 |
| ちょう | 少し | 「超」と逆 |
| えぐい | （味が）えぐい | 「すごい」は若者言葉 |
| 言えへん、書けへん | 言えない、書けない | 大阪では「言わない」「書かない」 |
| 考えときます | 遠回しの断り | 返答では使わない |
| よろしおすなあ | 本心の称賛にも、皮肉にもなる | 本心なら理由を添える |

## 10. 使わない語

- 見下す、罵る: 〜よる、〜しとる、おる（本動詞）、〜けつかる、〜やがる、〜くさる、ほざく、しばく、どつく
- ぞんざい: 〜け（要るけ？）、さよけ
- 大阪の言葉: せや、〜ねん、〜てん、けえへん、言いはる、〜まっせ、〜でっせ、おます、おまへん、なはれ、飴ちゃん、いてる、〜してもた、〜っちゅう、めばちこ
- 新しい言い方（はんなり・こってりでは使わない）: めっちゃ、むっちゃ、〜へんかった、〜へんくなる、高なる、〜ねんか、嘘やん
- 東京の言い方: 〜さ、〜っけ、〜じゃん、〜ちゃって、文頭の「やから」
