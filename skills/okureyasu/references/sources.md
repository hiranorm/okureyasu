# 出典と参考資料

## 京ことばの文法と語彙

このスキルの文法・語彙・京阪の違いの記述は、主に次のサイトの内容を、このスキルの用途に合わせて自分の言葉でまとめたものです。サイトの本文や表を写してはいません。例文はすべてこのスキルのために作りました。誤りがあれば、それはまとめた側の誤りです。

- 「京言葉」 https://www.akenotsuki.com/kyookotoba/
  - 第1部 文法（名詞と代名詞、助詞、形容詞、形容動詞、動詞、副詞、接続語、断定の「や・にゃ」、丁寧語、待遇表現）
  - 第3部 京都言葉と大阪言葉の違い、京都言葉と東京言葉の違い
  - 第4部 語彙、京の挨拶
  - 新方言、用語の解説、京ことばのススメ、京ことばつれづれ帳

同サイトが参考文献として挙げている資料のうち、京ことばを深く調べるときに役立つものです。
