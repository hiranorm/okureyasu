# 京ことば 文法の早見

SKILL.md 4章の詳細です。言い換えで長い文章を扱うときと、活用で迷ったときに読みます。対象は京都市の旧市街で話されてきた町方の京ことばです。例文はこのスキルのために作ったものです。事実関係は「京言葉」（akenotsuki.com/kyookotoba/）ほかの資料に拠っています（[sources.md](sources.md)）。

## 1. 断定と丁寧

| 前に来る語 | 常体 | 丁寧（普通） | 丁寧（高） |
|---|---|---|---|
| 名詞・の | 〜や | 〜どす（あっさりでは〜です） | 〜でございます |
| 形容詞 | 〜い | 〜う＋おす（高うおす） | 〜う＋ございます（高うございます） |
| 動詞 | 〜る | 〜ます | 〜ます（動詞を敬語にする） |

- 「どす」は「で＋おす」が縮まった形です。活用は どす／どした／どして／どすやろ（→どっしゃろ）。
- 「おす」の活用: おす／おした／おして／おすやろ（→おっしゃろ）／おへん（否定）／おへなんだ（否定の過去）。
- 「ます」の否定は ません、否定の過去は ませなんだ。「書かへん」の丁寧形として「書かしません」もあります。
- 「です」は明治以降に広まった形で、年配の話し手も「どす」と混ぜて使います。あっさりでは「です」、はんなりでは「どす」を主にして「です」も混ざってよい、こってりでは「どす」と「ございます」にします。
- 京ことばでは「や」と「ます／どす」が同じ文に並べます: しますやろ、どすやろ、しましたんや、そうどすさかい。東京語では「しますのだ」とは言わないので、ここは京ことばらしさが出るところです。
- 「や」は文の先頭に立ちません。「そや」「そう」を先に置きます: そやけど、そやさかい、そやかて、そうどすけど。
- 強い苛立ちでは古い形の「じゃ」が出ます（何するんじゃ）。このスキルでは使いません。
- 「〜やないか」は「〜ではないか」が変わった形で、断定の「や」とは別物です。「〜やんか」「〜やん」にも縮まります。

### 丁寧さの段

| 段 | 動詞「ある」 | 形容詞「よい」 | 名詞「ここ」 |
|---|---|---|---|
| 常体 | ある | ええ／よい | ここや |
| 丁寧 | あります | よろしおす | ここどす |
| 丁寧（高） | ございます | よろしゅうございます | ここでございます |

「ます」「どす」「おす」は丁寧にするだけで、相手を敬う意味はありません。相手の動作には3章の敬語を別に付けます。

## 2. 「〜のだ」にあたる形

「の＋や」は崩れて「んや」「にゃ」、また「ね」（「の＋え」から来たとも）になります。

| 形 | 響き | 例 |
|---|---|---|
| 〜のや | やや堅い、書き言葉寄り | 止まってしまうのや |
| 〜んや | 話し言葉 | 止まってしまうんや |
| 〜にゃ | 話し言葉、後ろに助詞が続くとき多い | 止まってしまうにゃわ、するにゃろ |
| 〜ね | 話し言葉、言い切るとき多い | 止まってしまうね |

- 過去形と形容詞の後には「にゃ」「ね」が付きません。「んや」か「のや」だけです: したんや、なかったんや、むつかしいんや（×したにゃ、×したね）。
- 直前が「ん」なら「んや」になりません: 言わへんのや／言わへんにゃ／言わへんね。
- 「それは私のや（私のもの）」の「の」は崩れません。
- 丁寧形にも付きます: 済ましてきましたんや、これは何どすにゃ、行かはりますにゃわ。
- 「にゃ」「ね」の前では、る で終わる動詞の「る」が「ん」になることが多いです: するにゃ→すんにゃ、いるね→いんね。多用すると「できる」と「できん」の区別がつかなくなるので、技術の話ではほどほどにします。
- 大阪の「〜ねん」「〜ねや」「〜てん」は使いません。

## 3. 敬語

### はる（いちばん軽い敬語）

利用者、第三者、身内にも使えます。命令形はありません。活用は はる／はった／はって／はります／はらへん。

| 動詞の種類 | 付き方 | 例 |
|---|---|---|
| 5段動詞 | 未然形（あ段）に付く | 言わはる、書かはる、使わはる、行かはる、待たはる、読まはる |
| 1段動詞（3拍以上） | 連用形に付く | 起きはる、決めはる、食べはる、調べはる |
| 1段動詞（2拍） | 連用形、または「や」を挟む | 見やはる／見はる、いやはる／いはる、出やはる |
| 来る | 「や」を挟む | きやはる／きはる |
| する | 「や」を挟む | しやはる／しはる |
| 〜ている | 「い」が落ちる | してはる／したはる、言うてはる／言うたはる |

- 大阪では5段動詞に連用形で付けます（言いはる、書きはる）。京都の目印は「言わはる」です。
- 自分の動作には付けません。

### お〜なはる・なはい

「お読みなはる」（お読みになる）。命令形は「なはい」（縮まって「ない」）。大阪の「なはれ」ではありません。「しなはい」「しなはんな」は丁寧な指図と禁止です。このスキルではこってりで、たまに使う程度です。

### お〜やす（いちばん高い敬語）

連用形を「お」と「やす」で挟みます: お書きやす（お書きになる／お書きなさい）、おしやす（なさる）、お見やす（ご覧になる）、おいでやす、おこしやす。

| 形 | 例 |
|---|---|
| 現在 | お決めやす |
| 過去 | お決めやした |
| 指図（希求） | お決めやす（お決めください） |
| 質問 | お決めやすか |

- 「〜て＋おくれやす」は「〜とくれやす」に縮まります（「てお」が「と」になる）: 見とくれやす、待っとくれやす、教えとくれやす。こってりでは縮める前の「〜とおくれやす」も使います。
- 「〜て＋おいやす」は「〜といやす」（〜していらっしゃる／〜していらっしゃい）。
- 「お〜やっしゃ」は「お〜やす」の派生で、「通しとおくれやっしゃ」のように使います。こってりで、ごくたまに。
- 「お〜やす」の否定（お書きやさへん）はほとんど使われません。

## 4. 見下す言い方

- 「〜よる」（しよる、言いよる）、「〜ておる／〜とる」（何しとるの）は、京都の旧市街では見下しや呆れの響きを持ちます。西日本の他の地域のように進行の意味にはなりません。
- 「おる」に敬語は付きません。敬語は「いる」の側に付けます（いやはる、おいやす）。
- 京都では江戸時代から「いる」がふつうです。「西日本だから おる」と考えて「おる」を多用するのは誤りです。
- 謙譲の「おります」（担当しております）は使えます。
- 「〜けつかる」「〜やがる」「〜くさる」はさらに強い罵りです。使いません。

## 5. 否定

| | ん | へん |
|---|---|---|
| 現在 | 読まん | 読まへん |
| 推量 | 読まんやろ | 読まへんやろ |
| 〜しないで | 読まんと、読まいで、読まんで | 読まへんで、読まへいで |
| 〜しないと | 読まんと | 読まへんと |
| 過去 | 読まなんだ | 読まへなんだ（→読まへんだ） |
| 〜しなかったら | 読まなんだら | 読まへなんだら |
| 〜しなくなる | 読まんようになる | 読まへんようになる |
| 〜しないでおく | 読まんとく、読まんとこ（う） | — |

- 「読まへんかった」は京都と東京の形を掛け合わせた新しい言い方です。あっさりでは使えます。
- 「〜なければならない」は「〜なならん」「〜なあかん」（せなあかん、書かなあかん）。
- 「ある」の否定は「あらへん」（「あらん」とは言わない）。
- 「ん」を好む動詞: 知らん、わからん、かなん、あかん。「よう〜ん」「〜かもしれん」も「ん」。
- 「〜していない」は「〜してへん」が一番ふつうです（書いてへん、見てへん）。

### 「へん」の付き方

| 動詞 | 付き方 | 例 |
|---|---|---|
| 5段動詞 | 未然形 | 書かへん、使わへん、あらへん、待たへん |
| 1段動詞（え段で終わる） | 連用形＋へん | 上げへん、決めへん、食べへん |
| 1段動詞（い段で終わる） | 連用形＋ひん | 起きひん、落ちひん、借りひん |
| 2拍の1段動詞 | 延ばして へん／ひん、または やへん | 見いひん／見やへん、いいひん／いやへん、出えへん／出やへん、寝えへん／寝やへん |
| 来る | | きいひん／きやへん |
| する | | しいひん／しやへん／せえへん |

- 大阪では5段動詞が「書けへん」「言えへん」とえ段になります。京都では「書けへん」「言えへん」は「書けない」「言えない」の意味です。取り違えると意味が逆転するので注意します。
- 「来る」の否定は 京都「きいひん」、大阪「けえへん」、神戸「こおへん」です。

## 6. 不可能

| 形 | 意味 | 例 |
|---|---|---|
| 可能形の否定（読めへん、書けへん、できひん） | 状況のためにできない | 電池が切れて動かへん、暗うて読めへん |
| よう＋否定（よう読まん、よう言わん、ようせん） | 能力がない、その気になれない | こんなややこしい字、よう読まん。そんなこと、よう言わんわ |

「ようできん」「よう読めん」は二つを混ぜた形で、誤用です。

## 7. 動詞の形

### ウ音便

「う」で終わる5段動詞は、「た」「て」の前で「う」になります。発音は前の母音とくっつきます。

| 動詞 | た形 | 発音 |
|---|---|---|
| 言う | 言うた | ゆうた |
| 買う | 買うた | こうた |
| 使う | 使うた | つこうた |
| 思う | 思うた | おもた（短くなる） |
| 違う | 違うた | ちごた |
| 払う | 払うた | はろた |
| もらう | もろた | もろた |

表記は「言うた」「使うた」「違うて」のように漢字＋うにすると読みやすくなります。「こうた」「ちごた」のような発音どおりの表記は、くだけた場面で少しだけ使います。

### 命令と指図

| 形 | 響き | 例 |
|---|---|---|
| 連用形 | 「〜しなさい」 | 見い、書き、待ち |
| 連用形＋や | 「〜しなさいよ」 | 見いや、書きや |
| 連用形＋いな | 「〜しなさいったら」 | 書きいな |
| て形＋いな | 「〜してってば」（頼み込む） | 書いていな（カイテーナ） |
| 〜とくれやす | 丁寧な依頼 | 書いとくれやす |
| 〜しよし | 丁寧な勧め（昭和以降、女性の言い方） | 書きよし（このスキルでは使わない） |

- 1段動詞の命令形は「い」で終わります: 見い、起きい、寝え、下げい。する の命令形は「せい」です。「見ろ」「しろ」は京都では高圧的に聞こえます。
- 依頼は否定形で頼むのが好まれます: 〜してくれへん？、〜してもらえへん？、〜してもらえませんやろか。

### 意向

- 5段・1段は共通語と同じ（書こう、寝よう）。日常は短く「書こ」「寝よ」。
- 来る→「こう」（見てこう）、する→「しょう」（どうしょう、そうしょう）。
- 推量は意向形を使わず「〜やろ」で言います（書くやろ、来はりますやろ）。

### 縮約

| もとの形 | 縮約 | 例 |
|---|---|---|
| 〜ている | 〜てる | 動いてる、待ってる |
| 〜ていない | 〜てへん | 書いてへん、見てへん |
| 〜てある | 〜たある（シタール） | 書いたある、置いたある |
| 〜てあらへん | 〜たあらへん | 何も書いたあらへん |
| 〜ておく | 〜とく | 直しとく、書いとく、置いとかんと |
| 〜ないでおく | 〜んとく | 言わんとこ、触らんとく |
| 〜てやる | 〜たる | 見たる |
| 〜てあげる | 〜たげる | 書いたげる、残しといたげて |
| 〜ておいで | 〜といで | 取っといで |

- 「〜してある」は物が主語のとき、共通語の「〜している」の場所でも使えます（ファイルが消えたある）。
- 仮定は「〜たら」。「〜ば」（書けば）は堅く聞こえます。ただし「せなならん」のような形では「な」を使います。

## 8. 形容詞

- 連用形はウ音便です: よく→よう、早く→早う、高く→高う、大きく→おおきゅう、よろしく→よろしゅう、うれしく→うれしゅう。
- 丁寧にするときは連用形＋おす／ございます: 高うおす、うれしおす、よろしおす、むつかしおす、おいしおす、ややこしおす。発音では「う」が縮んで「タコオス」「ヨロシオス」になります。表記は「よろしおす」「むつかしおす」のように縮めた形が読みやすいです。
- 「高いです」（形容詞＋です）はあっさりでは使えますが、はんなり以上では「高うおす」にします。
- 過去は「高かった」、丁寧な過去は「高うおした」。

## 9. 助詞

### 接続の助詞

| 語 | 意味 | 例 |
|---|---|---|
| さかい（に） | 〜から（理由） | 遅なりますさかい、先に始めとくれやす |
| し | 〜から、〜し | もう直したし、大丈夫やと思います |
| よって（に） | 〜から（古め） | こってりで、たまに |
| かて | 〜でも、〜だって | 誰かて間違えます。そう言わはったかて |
| けど | 〜けど | 動きますけど、遅おす |

- 「から」を京ことばの文に入れると、若い話し手に聞こえます。はんなり以上では「さかい」を主にします。
- 「そやから」より「そやさかい」「そやし」。

### 省かれやすい助詞

会話では が・は・を・と（引用）・へ を省くことがあります（ファイル開いて、ここ直しといた）。技術の説明では、主語や目的語が取り違えられない範囲にとどめます。

### 終助詞

| 語 | 意味・響き | 付く所 | 例 |
|---|---|---|---|
| な／なあ | 中立。いちばんよく使う。敬語と並べてもよい | ほぼどこでも | そうどすなあ、むつかしおすな |
| ね／ねえ | 共通語から入った「な」の仲間 | な と同じ | そうやね |
| え | 共通語の「よ」。柔らかい | 名詞、どす、ます、動詞 | そうどすえ、気ぃつけなあかんえ |
| で | 共通語の「よ」。名詞には直接付かない | や、どす、ます、動詞 | そこにありますで、ないで |
| の（ん） | 疑問。男女とも | 動詞、形容詞、や | そうなん？ 行かはるの？ |
| わ | 言い切り。男女とも | 動詞、形容詞、や、どす | もう行くわ、よう言わんわ |
| がな | 〜ってば、〜じゃないか | 動詞、形容詞、や、どす | ここにあるがな |
| かいな | 〜だっけ（思い出す）、反語 | か の位置 | 何やったかいな。そんなことあるかいな |
| かい | 反語（かいな より強い） | か の位置 | 誰が言うかい |
| や | 勧めや指図に念を押す | 連用形、て形 | 見いや、書いてや |
| け | 「か」のぞんざいな形 | | 使わない |

- 京都では質問に「か」、反語に「かい／かいな」を使い分けます。
- 「疑問詞＋え」（誰え、何え）は使えますが、「何どすえ」のように どす を挟んだ形は使われません。
- 告知の「よ」（〜するよ）は共通語に聞こえます。命令や禁止に添える「よ」（せいよ、言うなよ）は京都にもあります。
- 「〜さ」「〜っけ」は京ことばにありません。

## 10. 指示語と人称

- こそあど: ここ／そこ／あこ（あそこ）／どこ。こない／そない／あない／どない は大阪の言葉とする資料もあるので、このスキルでは使いません（こう、そう、ああ、どう を使う）。
- 「そ」は「ほ」になることがあります（それなら→ほな、ほれなら）。「ほな」は日常の言葉として使えます。
- 一人称: わたし（このスキルの既定）、わたくし（改まり）。「うち」は使う世代と場面が限られます。
- 二人称: あんた（「あなた」が変わった形）、あんたはん（丁寧）。名前が分かるなら名前で呼ぶのがふつうです。このスキルでは主語を言わずに「はる」で示します。
- 三人称: あの方、あちらさん、あの人。

## 11. 音のくせ

- 1拍の名詞は延ばします: 気ぃ、目ぇ、手ぇ、歯ぁ、値ぇ、木ぃ。助詞が付いても延びます（手ぇが空いたら）。
- 「〜の」「〜にゃ」の前の「る」は「ん」になります: 何すんの、いんね。
- 「さ」行が「は」行になることがあります: さかい→はかい、そんな→ほんな。このスキルでは「ほな」以外は使いません。
- アクセントは文字では表せません。京阪式アクセントの解説は sources.md の資料にあります。
