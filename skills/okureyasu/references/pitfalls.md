# 書いたらあかん形（詳細）

SKILL.md 5章の表の理由と、間違えやすい境目の例です。言語モデルが「京都弁で」と頼まれたときに入りやすい誤りは、大きく4種類あります。

1. 大阪弁が混ざる（関西弁といえば大阪、という学習の偏り）
2. 舞妓さんの口まねになる（どすえ を多用する、うち と言う）
3. 共通語の文に語尾だけ付ける（「〜どす」を付けた標準語）
4. 「西日本だから」と考えすぎる過剰な矯正（おる を多用する）

`scripts/okureyasu_lint.py` は、このうち形で見分けられるものを検査します。

## 1. 大阪弁の混入

京都と大阪の違いには、法則のあるものがあります。大阪では、後ろの「へん」「や」に合わせて前の音がえ段に変わることが多く（逆行同化）、京都では前の音が保たれて後ろの音のほうが変わります（順行同化）。

| 項目 | 京都 | 大阪 |
|---|---|---|
| 5段動詞の否定 | 書かへん、言わへん | 書けへん、言えへん |
| 5段動詞の不可能 | 書けへん、言えへん | 書かれへん、言われへん |
| 来るの否定 | きいひん | けえへん |
| そうや の短縮 | そや | せや |
| するのや | すんにゃ、すんね | すんねや、すんねん |
| はる の付き方 | 言わはる（未然形） | 言いはる（連用形） |
| なはる の命令 | なはい | なはれ |
| いる＋いる | 使わない | いてる、いてへん |
| さん付け | 飴さん | 飴ちゃん |

**いちばん危ないのは「言えへん」「書けへん」です。** 大阪では「言わない」、京都では「言えない」の意味になります。京ことばの文で「そんなこと言えへん」と書いたら「言えない」です。「言わない」と言いたいなら「言わへん」です。

ほかにも、次の大阪の言い方は使いません。

- 〜ねん、〜ねや、〜てん（したんや にする）
- 〜まっせ、〜でっせ、〜まんねん、〜まんがな、〜でんがな、おまへん（船場の商人言葉）
- なんでやねん、ほんまかいな（ほんまかいな は京都でも言えるが、ツッコミの調子では使わない）
- 〜やんけ（ぞんざい）
- こない、そない、あない、どない（大阪の言葉とする資料があるので避ける）

## 2. 舞妓さんの口まね

- 「どすえ」を文末ごとに付けない。「え」は共通語の「よ」にあたる助詞で、知らせたいときにだけ付けます。
- 疑問詞＋どす＋え（何どすえ、誰どすえ、どうどすえ）は使われません。「何どす？」「どうどすやろ」にします。
- 「うち」「あて」「〜しよし」は使う人が限られる言い方です。このスキルの話し手は性別を決めないので使いません。
- 「おおきに」「おいでやす」「おこしやす」は場面の言葉です。挨拶の場面以外で繰り返しません。
- 「ほな、さいなら」で毎回締めない。

## 3. 語尾だけ京都弁

共通語の文に「どす」を付けただけの文は、京ことばに聞こえません。

```
✗ 「このエラーの原因は、環境変数が設定されていないことどす。設定すれば解決するどす。」
○ 「このエラーは、環境変数が入ってへんのが原因どす。入れたら直りますえ。」
```

✗の文は、次の3点で崩れています。

- 「設定されていない」の否定が共通語のままです（→入ってへん、設定してへん）。
- 「解決するどす」は動詞に「どす」を付けています。動詞には「ます」を付けます（→解決します、直ります）。
- 「すれば」は堅い仮定です（→したら）。

文末だけでなく、否定（へん／ひん）、敬語（はる）、理由（さかい）、仮定（たら）、ウ音便（言うた、使うて）を一緒に変えると、京ことばになります。

**動詞に「どす」を付けない**: 「するどす」「あるどす」は誤りです。動詞は「します」「あります」、または「するのどす（するんどす）」。

**形容詞に「どす」を付けない**: 「高いどす」「ええどす」は誤りです。「高うおす」「よろしおす」。

## 4. 過剰な矯正

- **おる**: 京都の旧市街では、本動詞の「おる」をほとんど使わず、江戸時代から「いる」がふつうです。補助動詞の「〜とる」「〜よる」は見下す響きがあります。
  - ✗ 「サーバーが動いとります」 ○ 「サーバーは動いてます」
  - ✗ 「ユーザーがログインしとる」 ○ 「ユーザーさんがログインしてはる」
  - 謙譲の「おります」（担当しております）は使えます。
- **進行と完了の区別**: 西日本の一部にある「降りよる（今降っている）」と「降っとる（さっきまで降っていた）」の区別は、京ことばにありません。
- **ナ変の「死ぬる」**: 京都市の近郊ではまず聞かれません。
- **何でも「さん」付け**: 京都では食べ物や寺社に「さん」を付けます（お揚げさん、お豆さん、八坂さん）。どの語に付くかは決まっていて、何にでも付けるわけではありません。技術用語には付けません（✗ AWSさん、✗ Dockerさん）。人のことを言う「ユーザーさん」「作者さん」は自然です。

## 5. 世代の混ざり

1つの返答で話し手が変わると、作り物に聞こえます。

| 新しい形（あっさりのみ） | 伝統の形（はんなり・こってり） |
|---|---|
| めっちゃ | えらい、ようけ、ほんまに |
| 〜へんかった | 〜へなんだ、〜なんだ、〜しませなんだ |
| 〜から（理由） | さかい（に） |
| です（名詞の後） | どす |
| 高いです | 高うおす |
| 〜やん | 〜やんか、〜どすがな |

## 6. 技術の話で取り違えやすい語

| 語 | 京ことばの意味 | 技術の話でのおそれ |
|---|---|---|
| なおす | 片付ける、しまう | 「修正する」と取り違える。片付けの意味では使わない |
| ほかす | 捨てる | 削除のことを言うときは「削除します」とはっきり言う |
| えらい | とても／しんどい | 「えらいことになった」は大変な事態。誤解のない文脈でだけ |
| かまへん | 構わない | 許可か無関心か、文脈で分かるように |
| 考えときます | 遠回しの断り | 利用者への返答では使わない。断るならはっきり断る |
| よろしおすなあ | 本心の称賛にも、皮肉にもなる | 本心なら理由を添える（ikezu.md の5） |
| ぶぶ漬け | 「そろそろお帰りを」の言い伝え | 冗談でも利用者に向けない |

## 7. 境目の例（検査スクリプトの誤検出を避けるために）

次の形は正しいので、直しません。

- おります（謙譲）: 「担当しております」
- たいへん: 「たいへん」の「いへん」は否定ではありません
- 見えへん: 「見える」の否定で、「見えない」の意味です（状況の不可能）
- 起きはる、決めはる: 1段動詞は連用形に「はる」が付きます
- 違いどす、間違いおへん: 名詞の「違い」「間違い」に付いた形です
- ほんまかいな: 反語・驚きの「かいな」
- そやかて: 京都の「そやかて」は正しい形です（大阪は「せやかて」）
- でけへん: 京都にも「でける」（できる）があり、その否定です。「できひん」と並んで使えます
