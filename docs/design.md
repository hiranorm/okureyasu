# 設計

## 構成

```
okureyasu/
├── skills/okureyasu/          # スキル本体（配布されるのはここだけ）
│   ├── SKILL.md               # 呼ばれたときに毎回読まれる。芯の規則と NG 一覧
│   ├── references/            # 必要なときだけ読む詳細
│   │   ├── grammar.md         # 活用と文法の早見
│   │   ├── vocabulary.md      # 語彙と言い回し
│   │   ├── pitfalls.md        # 書いたらあかん形の詳細
│   │   ├── ikezu.md           # いけずの作法
│   │   ├── ai-tics.md         # AIの定型の言い換え
│   │   ├── examples.md        # 場面ごとの例
│   │   └── sources.md         # 出典
│   ├── scripts/okureyasu_lint.py  # 京都らしくない形の検査
│   └── LICENSE
├── tests/                     # 検査スクリプトの回帰テスト
├── evals/                     # スキルの評価ケース（skill-creator のケース形式）
├── docs/                      # このファイルなど（開発者向け）
└── .claude-plugin/            # Claude Code プラグインの定義
```

スキルの定義は `skills/okureyasu/` の1か所だけに置きます（yomiyasu のようにルートと二重に持たない）。

## 決めたこと

### 1. 芯の規則は SKILL.md 本体に置く

話し方のスキルは、返答のたびに効いていなければなりません。references は一度読まれれば良いほうなので、毎回守る規則（範囲、濃さ、文法の芯、NG 一覧、いけずの約束、定型の消し方、点検の順）は SKILL.md 本体に置き、語彙と詳細だけを references に出しました。SKILL.md は 500 行以内（Agent Skills 仕様の目安）に収めています。

### 2. 京ことばにするのは地の文だけ

コード、コマンド、パス、数値、エラーの引用、専門用語は標準のまま残します。ファイルに書くもの（コードのコメント、コミットメッセージ、PR の説明、ドキュメント）も標準のままです。後で別の人が読むからです。利用者が頼んだときだけ変えます。

### 3. 婉曲は態度に、確度には掛けない

京ことばの婉曲を確度に掛けると、「バグです」が「ちょっと気になるとこがあるかもしれまへんなあ」になり、情報が変わります。yomiyasu の「意味の4点（主張、比重、言い切りの強さ、文の働き）」を借りて、変えてはいけないものを決めました。

エラー、テストの失敗、断り、取り消せない操作の確認、セキュリティと安全の注意では、いけずも言いさしも使いません。

### 4. 濃さは3段、1返答に話し手は1人

| 濃さ | 話し手 |
|---|---|
| あっさり | 今の京都の人の普段の話し方（常体が中心。や、へん、はる、し、わ。です・ます は頼むときと謝るときだけ） |
| はんなり（既定） | 町方の店の主の丁寧な話し方（ます、どす、おす、はる、さかい） |
| こってり | 旧市街の年配の店の主の客あしらい（ございます、お〜やす、へえ） |

既定を「はんなり」にしたのは、「京ことばのススメ」の指摘によります。伝統方言の色が薄い話し方は、よそからは「訛った共通語」や関西弁の一種にしか聞こえず、京都らしさが伝わりません。一方で「どす」を文ごとに付けると舞妓さんの口まねになるので、はんなりは「ます」を主に、名詞の後と形容詞に「どす」「おす」を使う配分にしています。この配分は「京ことばつれづれ帳」の文章（丁寧な書き言葉の京ことば）を手本にしました。

世代の違う形（「どす」と「めっちゃ」）を混ぜると別人に聞こえるので、濃さごとに話し手を1人に決めています。

### 5. NG 一覧はモデルの既定の誤りから作る

言語モデルに「京都弁で」と頼むと、次の誤りが出やすいことが分かっています。

- 大阪弁の混入（せや、〜ねん、けえへん、言いはる、なはれ、飴ちゃん）
- 形容詞＋どす（高いどす）、動詞＋どす（するどす）
- い段の後の「へん」（起きへん）
- 京都では見下す響きのある「おる」「〜とる」
- 文頭の「や」（やけど）
- 共通語の「〜っけ」「〜さ」「だ」

これを SKILL.md の表にし、同じものを `okureyasu_lint.py` で検査できるようにしました。

### 6. いけずの約束

京都人同士なら言いさしで通じますが、利用者は京都人とは限りません。いけずは「種明かしまでが一組」とし、情報はいけずの後の本音と手立てで運びます。いけずを消しても返答の中身が変わらないことを目安にしています。

### 7. 検査スクリプト

- 標準ライブラリだけで動きます（形態素解析を使わない）。インストールの手間をなくすためです。
- 正規表現なので、文脈を読む判断（「言えへん」が「言えない」か「言わない」か）はできません。その種の項目は info に留めています。
- 誤検出を避けるため、正しい京ことばの文（「京ことばつれづれ帳」）で検査して 0 件になることを確かめています。回帰テストは `tests/test_okureyasu_lint.py`。

### 8. 出典の扱い

「京言葉」サイトは、改変しない・無断で商業利用しない条件で転載を許しています。このリポジトリは MIT ライセンス（商用利用を許す）なので、サイトの文章や表は写さず、文法上の事実だけを自分の言葉でまとめ、例文はすべて自作しました。出典は [skills/okureyasu/references/sources.md](../skills/okureyasu/references/sources.md) に記しています。

## 制約と今後

- 文字ではアクセントを表せません。京ことばらしさの大きな部分（京阪式アクセント、遅上がり）は伝えられません。
- モデルの京ことばは、資料にない語や形を作ることがあります。検査スクリプトは既知の誤りしか拾えません。
- 京都出身の話者による確認はまだです。誤りの指摘を歓迎します。
