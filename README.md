# okureyasu（おくれやす）

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

AI の話し言葉を京ことば（京都弁）に仕立てる [Agent Skill](https://agentskills.io/) です。中身ははっきり、物言いははんなり、いけずは一滴。

AI らしさを消すスキルには [yomiyasu](https://github.com/nanaism/yomiyasu) や [natural-japanese](https://github.com/coji/natural-japanese) があります。どちらも AI の癖を引き算して、平らな日本語に戻します。okureyasu はその逆で、話し手を一人決めて人の声を足し、AI の定型が入る隙間をなくします。京都の老舗の主人は「素晴らしい質問ですね！🎉」とは言いません。

## こうなります

「京ことばでこのコードレビューして」と、名前が一文字だらけの関数（`proc(d)`、`1.1` と `99999` が素のまま）を渡したときの、Claude Opus 5.5 の実際の返答の書き出しです。

**okureyasu なし**（モデルが自力で書いた京都弁）

> まあ、えらいすっきりした短いコードどすなあ。名前もみぃんな一文字で、書かはったご本人さんしか読めへんよう、よう工夫してはりますこと。
>
> ……ほな、いけずはこのへんにして、ちゃんと見さしてもらいますえ。
>
> ## 気になったとこ
>
> ### 1. 名前がなんも語ってくれはらへん

**okureyasu あり**

> えらい無口なコードどすなあ。`d` も `r` も `x` も、`'s'` も `'p'` も、誰も名乗らはらへん。……ほんまのこと言うたら、動きはこれで合うてます。そやけど、半年後に読んだら何の処理か分からんようになりますさかい、名前と数字に意味を持たせときましょ。
>
> 気になったとこを、大事な順に並べます。

なしのほうは、いけずが書いた本人に向いていて、見出しと太字で区切った AI の書式のままです。同じ返答の後半には大阪の「せや」も出ました。ありのほうは、いけずをコードに向けて一つだけ言い、すぐ本音に移っています。7 場面で比べた結果は [docs/evaluation.md](docs/evaluation.md) にあります。

エラーの報告、断り、取り消せない操作の確認では、いけずを使わず結論から言います。

## 使い方

```bash
npx skills add hiranorm/okureyasu
```

画面の案内に従って、利用するエージェント（Claude Code、Cursor、Codex など）を選んでください。

あとは「京都弁で話して」「京ことばで答えて」「/okureyasu」と頼むだけです。その会話のあいだ、京ことばで話します。「標準語に戻して」で戻ります。

| 頼み方 | すること |
|---|---|
| 京都弁で話して、/okureyasu | 以後の返答を京ことばで |
| /okureyasu（だけ） | 直前の返答を京ことばで言い直す |
| この文章を京ことばにして | 渡した文章を、意味を変えずに言い換える |
| あっさりで／こってりで | 濃さを変える（既定ははんなり） |
| いけずは要らん | 京ことばのまま、いけずだけやめる |

濃さは3段あります。

- **あっさり**: 今の京都の人の普段の話し方。「直しといたし、もういっぺん動かしてみてくれはる？」
- **はんなり**（既定）: 町方の店の主の丁寧な話し方。「直しときましたさかい、もういっぺん動かしてみとくれやす。」
- **こってり**: 旧市街の年配の店の主の客あしらい。「直しときましたさかいに、もういっぺん動かしとおくれやす。」

## 守ること

- **京ことばにするのは、話しかける地の文だけ**です。コード、コマンド、パス、数値、エラーの引用、専門用語は標準のまま残します。ファイルに書くもの（コードのコメント、コミットメッセージ、PR の説明、ドキュメント）も、頼まれなければ標準語のままです。
- **婉曲は物言いに掛けて、中身には掛けません**。「バグです」は「バグどす」で、「ちょっと気になるとこがあるかもしれまへんなあ」にはしません。
- **本物に近い京ことば**を目指します。大阪弁の混入（せや、〜ねん、けえへん、言いはる）、形容詞＋どす（高いどす）、舞妓さんの口まね（何どすえ）を避けます。

## いけずの約束

1. いけずの後には、同じ返答の中で本音を言う（種明かし）。
2. コードや状況に向けて、人には向けない。
3. 1 返答に 1 つまで。なければ入れない。
4. エラー、断り、危険な操作の確認、困っている人には使わない。
5. 本気で褒めるときは「ほんまに」と理由を付けて、いけずと区別する。
6. 最後は手を貸す。

## 検査スクリプト

京都らしくない形を拾う検査スクリプトが付いています。標準ライブラリだけで動きます。コードブロック、インラインコード、URL、引用は検査しません。

```bash
python3 skills/okureyasu/scripts/okureyasu_lint.py --level hannari reply.md
```

```text
reply.md:1:1: [error] osaka-seya 「せや」 → そや（「せや」は大阪の形）
reply.md:2:6: [error] haru-renyou 「言いはった」 → 言わはった（5段動詞の「はる」は未然形に付く（連用形に付けるのは大阪の形））
reply.md:3:1: [error] adj-dosu 「高いどす」 → 高うおす／高うございます（ウ音便＋おす）（形容詞に「どす」は付かない）
```

## 推敲スキルと一緒に使うとき

yomiyasu や natural-japanese は書いて残す文章を標準語で整え、okureyasu は話しかける声を受け持ちます。両方入れたときは、ファイルに書く文章は推敲スキル、利用者への返答は okureyasu に任せてください。

## 苦手なこと

- 文字ではアクセントを表せません。京阪式アクセントは京ことばらしさの大きな部分ですが、伝えられません。
- モデルが資料にない語や形を作ることがあります。検査スクリプトは既知の誤りしか拾えません。
- 京都出身の方による確認はまだです。おかしな京ことばを見つけたら、Issue で教えとくれやす。

## 出典・謝辞

京ことばの文法・語彙・京阪の違いは、主に「[京言葉](https://www.akenotsuki.com/kyookotoba/)」の内容を自分の言葉でまとめたものです。サイトの文章は写さず、例文はすべて自作しています。詳しくは [sources.md](skills/okureyasu/references/sources.md) にあります。

AI の定型の見つけ方は、[yomiyasu](https://github.com/nanaism/yomiyasu) と [natural-japanese](https://github.com/coji/natural-japanese) に多くを負っています。
